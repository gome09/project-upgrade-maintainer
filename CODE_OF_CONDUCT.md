# Code of Conduct

Project Upgrade Maintainer aims to keep collaboration technical, respectful, and safe.

Contributors and maintainers are expected to:

- discuss ideas and reviews in good faith;
- critique code and behavior rather than people;
- avoid harassment, threats, discrimination, doxxing, or disclosure of private information;
- avoid publishing credentials, private repository data, or exploit details in public issues;
- respect maintainer decisions on repository scope, safety boundaries, and moderation.

Maintainers may edit, hide, lock, or remove contributions and participation that violate these expectations, especially when necessary to protect security or privacy.

For security-sensitive matters, follow `SECURITY.md` rather than posting details publicly.
